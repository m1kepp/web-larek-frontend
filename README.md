# Web Larek

## Описание проекта

**Web Larek** — это интернет-магазин цифровых товаров, разработанный в рамках учебного проекта.

Пользователь может:

- просматривать каталог товаров;
- открывать подробную информацию о товаре;
- добавлять товары в корзину;
- удалять товары из корзины;
- оформлять заказ;
- вводить данные доставки и контактную информацию.

Проект реализован с использованием архитектуры **MVP (Model–View–Presenter)**, что позволяет разделить логику работы с данными, отображение интерфейса и управление взаимодействием пользователя.

---

## Технологии

В проекте используются:

- **TypeScript** — типизация и разработка клиентской логики;
- **JavaScript ES6+** — современный синтаксис;
- **Webpack** — сборка проекта;
- **SCSS** — стилизация интерфейса;

---

# Архитектура проекта

Проект построен по паттерну **MVP**.

## Model

Отвечает за хранение и управление данными.

Используются модели:

- `ProductsModel` — хранение списка товаров;
- `BasketModel` — управление товарами в корзине;
- `OrderModel` — хранение данных заказа.

---

## View

Отвечает за отображение интерфейса.

Основные компоненты:

- `Card` — карточка товара;
- `CardPreview` — подробный просмотр товара;
- `Catalog` — вывод каталога;
- `Basket` — отображение корзины;
- `Order` — форма оформления заказа;
- `Contacts` — форма контактных данных.

---

## Presenter

Связывает модели и представление.

Основной класс:

```
AppPresenter
```

Отвечает за:

- загрузку товаров через API;
- передачу данных в каталог;
- управление действиями пользователя;
- обработку оформления заказа.

# Установка проекта

Для работы проекта необходимы:

- Node.js версии 18 или выше;
- npm.

Установка зависимостей:

```bash
npm install
```

---

# Запуск проекта

Для запуска проекта в режиме разработки:

```bash
npm run start
```

После запуска приложение будет доступно по адресу:

```
http://localhost:8080
```

---

# Сборка проекта

Для создания production-сборки:

```bash
npm run build
```

После успешной сборки создаётся оптимизированная версия проекта.

# Работа с API

Проект получает данные о товарах с API Web Larek.

Используются запросы:

### Получение списка товаров

```
GET /product
```

### Отправка заказа

```
POST /order
```
